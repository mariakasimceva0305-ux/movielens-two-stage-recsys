# Двухэтапные рекомендации MovieLens

Отбор кандидатов по истории взаимодействий и переранжирование CatBoostRanker. Сравнение с популярными фильмами и item–item baseline на MovieLens ml-latest-small.

## Оценка

Одно глобальное временное разбиение, единый набор из 101 test-пользователя. Отсутствие рекомендаций даёт нулевой вклад, повторяющиеся фильмы не увеличивают NDCG.

На проверенном запуске 10.10.2026: popularity NDCG@10 0,2939 и Recall@10 0,0641; two-stage — 0,3218 и 0,0745. Покрытие обоих методов — 100%. У item–item NDCG@10 0,0016 и покрытие 7,92%; этот слабый baseline требует отдельного анализа кандидатов.

[Сохранённые метрики](artifacts/verified_20261010/metrics.json). Фильтр активности определяет когорту по всей истории; результат не является оценкой будущего продуктового трафика. Для устойчивого сравнения нужны несколько временных отсечек и отдельный анализ cold-start.

## Запуск

Скачайте [MovieLens ml-latest-small](https://grouplens.org/datasets/movielens/); каталог должен содержать ratings.csv и movies.csv.

```bash
pip install -r requirements.txt
python -m src.train --data-dir data/ml-latest-small --artifacts-dir artifacts --k-metrics 10
python -m pytest -q
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Код обучения и оценки — `src/`, API — `app/`. Новый запуск сохраняет модели и метрики в заданный `--artifacts-dir`; для независимого повторения используйте отдельную папку. Качество рекомендаций и эксплуатационная задержка оцениваются раздельно.
